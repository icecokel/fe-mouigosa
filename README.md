# fe-mouigosa

**수능 문제지를 펼쳤는데 과목이 프론트엔드인 모의고사 웹페이지.**

`fe-mouigosa`는 한국의 수능·평가원 모의고사 시험지를 웹으로 옮긴 듯한 경험을 만드는 프로젝트입니다. 프론트엔드 지식을 문제지와 OMR 답안지로 평가하고, 시험이 끝나면 한국식 성적표로 결과를 확인합니다.

## 핵심 경험

| 구분 | 내용 |
| --- | --- |
| 문제지 | A4 시험지 비율, 흰색 또는 옅은 종이색, 명조 계열 본문, 2단 문제 배치 |
| 문항 | 문제 번호와 배점, ①②③④⑤ 선택지, 코드와 지문 |
| OMR | PC에서는 시험지 옆에 고정, 모바일에서는 하단 Drawer로 제공 |
| 성적표 | 영역별 점수, 백분위, 등급, 취약 영역, 오답 문항 |

시험지 상단에는 다음 문구를 사용합니다.

```text
2026학년도 프론트엔드 개발자 모의평가
제 1교시
프론트엔드 영역
```

## 출제 범위

JavaScript, TypeScript, React, Browser, CSS, Web Performance, Design Pattern 등 프론트엔드 전반을 다룹니다.

모든 문항은 5지선다입니다. 각 문항을 지식 영역인 카테고리와 풀이 방식인 유형으로 나누며, 개념 판단·결과 예측·타입 분석·버그 찾기·렌더링 횟수 예측·브라우저 동작을 섞습니다. 카테고리와 유형 태그는 시험 중 노출하지 않습니다.

## 디자인 원칙

- 실제 시험지의 여백, 문항 번호, 구분선과 활자 중심으로 화면을 구성합니다.
- SaaS 스타일의 카드, 그림자, 그라디언트는 최대한 배제합니다.
- 코드는 읽기 쉬운 고정폭 글꼴을 사용하되 시험지의 전체 분위기를 유지합니다.
- 결과 화면도 대시보드 대신 표와 문서 중심의 한국식 성적표로 구성합니다.
- 모바일에서는 종이의 인상을 유지하면서 지문과 선택지를 읽고 답할 수 있어야 합니다.

## 현재 상태

React 19·Next.js 16으로 **문제지와 성적표 화면 시안**을 구현했습니다. 문제은행은 카테고리별 JSON 7개, 영역별 100문항씩 총 700문항입니다. 시작·재응시 때마다 중복 없이 최소 20문항을 무작위로 선별하고 순서를 섞습니다. 영역마다 2·3·4·5점 문항을 각각 25개씩 갖추었습니다. 문항당 배점을 유지하면서 총 100점, 영역별 14~15점에 가깝게 구성하며, A4 비율 지면에 4문항씩 배치합니다. 문제지와 OMR에서 선택한 답은 서로 반영됩니다. OMR의 시험 종료 버튼을 누르면 답안이 고정되고 성적표에 총점·영역별 점수·취약 영역과 전체 문항의 해답지가 표시됩니다. 각 해답에는 제출 답안·정답·해설·근거 링크를 제공합니다. 결과 공유는 점수 요약과 응시 링크를 전달하며, 공유 API를 지원하지 않으면 텍스트를 복사합니다. GitHub Star 버튼은 저장소로 연결됩니다. 20분 카운트다운은 모의고사 시작 버튼을 누르면 시작해 `00:00`에서 멈추며, 제출 시에도 멈춥니다. 백분위·등급은 비교 자료가 없어 `—`로 표시합니다. 현재 응시 상태는 새로고침하면 초기화됩니다.

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다. `npm run build`로 프로덕션 빌드를 검증할 수 있습니다.

## GitHub Pages 배포

Next.js 정적 export를 사용하며 `npm run build` 결과는 `out/`에 생성됩니다. GitHub Pages 프로젝트 사이트의 하위 경로를 로컬에서 확인하려면 `PAGES_BASE_PATH=/fe-mouigosa npm run build`를 실행합니다.

저장소는 [icecokel/fe-mouigosa](https://github.com/icecokel/fe-mouigosa)이며, Pages 배포 소스는 **GitHub Actions**로 설정되어 있습니다. `main`에 푸시하거나 Actions에서 `Deploy to GitHub Pages`를 수동 실행하면 `.github/workflows/deploy-pages.yml`이 Pages에서 제공한 하위 경로로 정적 파일을 배포합니다. 배포 주소는 [icecokel.github.io/fe-mouigosa](https://icecokel.github.io/fe-mouigosa/)입니다.

문제는 `content/questions/<category>.json`의 `questions` 배열에 추가합니다. `npm run check:questions`는 카테고리·문항 스키마·ID 및 동일 지문·코드 중복과 모든 영역을 포함한 100점 시험 구성 가능 여부를 검증하고 전체 문제은행 데이터를 생성합니다. 개발 서버와 빌드 시작 전에도 자동 실행됩니다. 추가 방법은 [문제 기여 안내](CONTRIBUTING.md)에 정리했습니다.

`npm run check`는 무작위 선별·100점 구성·채점을 포함한 모든 검증을 실행합니다. PR에서는 검증과 정적 빌드가 자동 실행됩니다.

`npm run check:countdown`은 남은 시간 계산과 표시를 확인합니다.

`npm run check:results`는 만점·오답·미응답·취약 영역 계산을 확인합니다.

실제 출제 문항과 배점 체계, 시간 만료 시 자동 종료 여부, 백분위·등급 산정 방식은 [기획서의 미정 사항](docs/기획서.md#9-미정-사항)에 남겨두었습니다.
